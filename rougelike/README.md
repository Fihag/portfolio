# 魔法幸存者

一款基于 Canvas 的轻量 Roguelite 生存小游戏：单机、零构建可双击，`npx serve` 开发，`npm test/lint` 护航。

## 在线游玩

🌐 **[立即开始游戏](https://rougelike-13h.pages.dev)** （`web/rougelike` 正式版，`debug.html` 仅本地 `?debug`）

手机端建议右下角全屏；桌面端方向键 + 数字键 + 空格暂停。

## 快速开始

```bash
# 零构建：双击 index.html 即可（file://）
# 或
npx serve web/rougelike -l 8123   # http
npx vite --open                   # ESM 热更新（可选，经典脚本直加载）
# 开发校验
npm install
npm test        # vitest 15 用例（冒烟 + 运行时帧模拟）
npm run lint    # eslint
```

## 游戏玩法

- **目标**：在密集浪潮中存活，获取经验强化武器
- **武器编队**：战前从 9 把武器中选最多 6 把入局（自动存档记忆），初始武器从编队内六选一；局内升级卡池只出现编队内武器的解锁卡
- **武器**：魔法弹、飞刃、冰霜、闪电链、陨石、暗影精灵、**圣光棱镜**（直线贯穿光束，进化后扇形扫射）、**诅咒瘴气**（毒云区域控制，中毒敌人死亡爆发传染）、**引力奇点**（优先吸附敌群最密处，到期爆炸，进化后分裂冲击波）
- **进化门槛统一**：每把武器 3 条门槛线（3+3+4 级）共 10 张强化卡 + 进化卡；各武器另有自由线（多重/衰减/束缚/传染等）不占门槛
- **等级溢出**：升级卡池全部选满后，剩余等级不弹选项，每级直接全属性 +5%（伤害/生命/移速/拾取）
- **难度**：简单 / 普通 / 困难 / 地狱 / **不可能**（`DIFFICULTIES` 单源 `js/config.js`）；不可能小怪 50% 词缀、10% 减伤、20% 减速免疫，Boss 减速 40%（不可能 50%，刺客免疫）
- **精英波次**：每 60 秒一波，预警期间普通怪照常刷新，不清场
- **刷怪批次**：按场上存量反向调节——场上 ≤3 只时每次刷 3 只、4~12 只刷 2 只、>12 只刷 1 只，保持场上压力
- **Boss**：死神骑士、虫巢母皇、暗影刺客（弹速 +30）、**熔岩巨兽**地狱/不可能 40% 出场，3200血，全弹速 +40，死亡 256 发新星；**天罚炮台**（原地弹幕要塞，固定降临地图正中心：常驻 0.27s 速射弹（基础弹速 395）/ 2.5s 扇形炮击 9 发 ±10° 连发两次（基础弹速 415）/ 4.5s 爆裂弹×3（基础弹速 415 射程 800）——逼近玩家 100 内或射程尽头爆炸，爆心 35 伤（半径 140）并分裂 30 发环形弹（12° 整圆，基础弹速 345；尽头引爆 465）/ 0.7s 预警扫射激光（长 1200 穿透，24 伤，冷却 6s）/ 每 8.5s 投放 3 只精英自爆虫（×1.4），2500 血 65% 减伤；子弹弹速随难度系数（简单×0.85 普通×1 困难×1.06 地狱×1.14 不可能×1.2）；**在场光环**：小怪刷怪频率 +10%、速度 +10%、血量/接触伤 +5%；**死亡神罚**：全图 100 颗陨石两波约 7s 坠落（预警 1s、半径 105、每颗 50 伤）；技能伤害随全 Boss 共用出场次数 +6%/次（封顶 4 次）并吃难度倍率）；Boss 掉落道具本局去重
- **幽月魔女**（特殊 Boss，整局固定两次，不计入常规轮换与出场次数，2500 血 25% 减伤）：击败第 2 / 第 5 个常规 Boss 后 10 秒降临——第 5 秒起屏幕震颤渐强，随后月之魔法阵降临（第二次降临先播镜片重组复活动画且**全数值 ×3**：7500 血，并全阶段额外 +15% 减伤）；降临后月光锁链把玩家**拽进异空间领域**（世界外独立地图：蓝紫深空、透明地板、双黑洞环绕、符文边界环）；领域内玩家被困至 Boss 死亡，副作用：回血 -70%、移速 -10%、**血量上限锁 150、圣物与死神之指全部失效**（出场恢复）；小怪全体冻结、刷怪暂停（纯 1v1）。Boss 走位保持 300±40 距离带环绕不贴脸，**被动·穿梭**：被逼到边界且玩家逼近时镜面点对称闪现对侧（CD 30s）。领域加成一阶段 伤×1.2/速×1.3/CD-20%，**二阶段（60% 血）翻倍** 伤×1.4/速×1.6/CD-40% 并**额外 +30% 减伤（合计 55%）**且变身无敌 2.5s，之后**无敌 5s → 破绽 8s** 循环（无敌期技能照放）。六技能：月刃环（360° **5 发细长月牙**弹幕弹速 280、**一阶段不反弹**（飞出领域即消散）/二阶段 7 发弹速 320 触界反弹 1 次，伤 14）、追月弹（3 颗追踪弹 160→300 加速，**转向迟钝可被玩家急转甩掉**，伤 20）、月光洗礼（3~5 个预警圈 0.9s 后落地伤 25）、镜月分身（2~3 只一击碎镜影）、满月收缩（边界光环留 50° 缺口向圆心碾压 170 速伤 22）、升月轰炸（升空 3.5s 无法选中+免伤：天际激光扫射+弹幕雨，砸落冲击 120 半径伤 27 + 硬直 0.8s 破绽）；死亡触发**镜面碎裂**演出（白闪+镜片迸散），领域崩塌送回原地图并恢复全部状态，掉落 Boss 道具
- **地图事件**：治疗祭坛 / 风险祭坛 / 传送门 + 屏外箭头；宝箱 5 种奖励（满血 / 护盾 / 爆发 / 经验书 / **抉择之匣**——下次升级 6 选 1）
- **新敌人**：**自爆虫**（冲锋贴近后 0.8s 引爆，提前击杀无损失）、**咒术师**（光环治疗周围小怪，集火优先级目标）；小怪携带个体侧翼方位角，远距离弧线包抄、120px 内直冲（玩家绕圈不再聚成一团）
- **灵魂宝库**：天赋 + 圣物（12 种：`影侍守卫` 受击 45% 眩晕 0.4s（对 Boss 无效）+ 10s 双影袭，不可升级；`抉择之冠` 升级选项恒为 6 个）/ 成就 8 种（含「万法归宗」：一局 6 武器全进化）/ 死神之指（手动世界坐标修复，刺客 60 半径自适应）
- **存档**：最佳记录按难度分档，`rogue_best_time_<难度>`；武器编队 `rogue_loadout`

## 开发说明

- 顶层共享作用域，按 `index.html` 顺序加载，新增文件保持依赖顺序（`00` → `game/ui`）
- 快捷键：`P/Esc` 暂停，`M` 静音，`T` 时停领域（穿戴圣物后），`F1` 调试面板
- 存档签名 `META_SALT`，篡改自动清除
