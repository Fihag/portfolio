# 拼豆统计 — 手绘风库存管理工具

纯前端、零依赖的拼豆(Perler Bead)库存统计网页。数据来自 `拼豆消耗统计表.docx`(221 色号初始库存)。

## 运行

直接双击打开 `index.html` 即可(数据存于浏览器 localStorage);或启动本地服务器:

```powershell
python -m http.server 8123
# 浏览器打开 http://127.0.0.1:8123
```

## 功能

- **库存总览**:221 色号按系列(A/B/C/D/E/F/G/H/M)分组展示,带剩余量进度条
- **预警机制**:库存低于 400 颗自动红色标记并汇总预警,顶部统计卡片显示预警数
- **消耗录入**:支持批量格式 `A01/5 A03/12 B07/3`,自动校验色号与库存,一键扣除
- **消耗历史**:每次记录带时间戳,可单条撤销回滚
- **统计**:总剩余 / 已消耗 / 预警色号数实时刷新
- **数据管理**:JSON 导出备份、导入恢复、一键重置为初始库存
- 移动端适配

## 目录结构

```
pinbei/
├── index.html      页面骨架 + 手绘风样式
├── style.css       手绘主题(蜡笔/纸张/手写,风格参照 turtle-soup)
├── js/
│   ├── data.js     221 色号初始库存(数据源:拼豆消耗统计表.docx)
│   └── app.js      核心逻辑(扣减/预警/历史/导入导出)
└── README.md
```

## 规则

- 初始库存:每个色号默认 1000 颗(部分色号按 docx 实际值,如 M04=2000、H02=3901)
- 消耗格式:`Axx/yy` 表示 Axx 色号消耗 yy 颗
- 预警线:库存低于 400 颗时红色预警,建议补货
