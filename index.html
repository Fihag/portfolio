关于

我是 Fihag。这里的东西没有路线图，全凭一时兴起： 想玩肉鸽，就写了个 Canvas 幸存者；想省下切 API 的麻烦，就写了个聚合轮询代理； 连拼豆的库存，都做成了带红色预警的网页。

原则很简单：能不依赖就不依赖，能本地跑就本地跑， 写完顺手部署到 Cloudflare Pages。这个页面本身也一样—— 原生 HTML、CSS、JavaScript，一个构建步骤都没有。
