# 魔法幸存者（Pigeon · Debug 版）

一款基于 Canvas 的轻量 Roguelite 生存小游戏：单机、无需构建、浏览器直接打开即玩。
本仓库为 **Debug 副本**，在正式版基础上附带调试面板，用于快速验证玩法与数值。

## 快速开始

- **正常游玩**：双击打开 `index.html`
- **调试游玩**：双击打开 `debug.html`（含 Debug 面板，游戏内按 `F1` 开关）

## 游戏玩法

- **目标**：在越来越密集的敌人浪潮中尽可能存活，获取经验强化武器
- **武器**：魔法弹、飞刃、冰霜、闪电链、陨石、暗影精灵，可组合进化
- **难度**：简单 / 普通 / 困难 / 地狱 / **不可能**，影响敌人属性、出怪频率与初始生命；不可能模式小怪可能携带词缀（迅捷 / 坚韧 / 爆裂 / 灼热 / 嗜血）
- **精英波次**：每 60 秒一波精英来袭（预警期间普通怪照常刷新），清空后获得宝箱奖励
- **Boss**：死神骑士（剑气/冲击波）、虫巢母皇（召唤/毒液）、暗影刺客（瞬影突进/影刃回旋），击杀掉落专属道具；**熔岩巨兽**为地狱/不可能模式特供（弹幕/喷发/跃击/硬化/召唤/狂暴），固定 40% 出场率
- **地图事件**：治疗祭坛、风险祭坛、传送门
- **屏外指示**：祭坛 / 宝箱 / Boss 在屏幕外时，屏幕边缘显示指向箭头与类型文字
- **灵魂宝库**：分「天赋」与「圣物」两个分区；圣物共 11 种，可自由穿戴/卸下，部分可升级
- **死神之指**：购买并穿戴后解锁（局内可切换自动/手动）

## Debug 面板（F1）

- **时间流速**：0~N 倍速、冻结全场、暂停自动出怪
- **自由出怪**：指定小怪/ Boss 直接召唤（含熔岩巨兽、熔岩幼体）、自定义出怪间隔
- **修改玩家**：等级 / 生命 / 移速 / 伤害倍率、回满血、立即升级、加经验、Boss 掉落、武器管理（添加/移除/满级进化）
- **修改怪物**：HP / 伤害 / 速度倍率（对新怪生效）、难度级、秒杀全场、清空
- **碎片与圣物**：碎片 添加/设为/快捷增减/清零；圣物 授予/升级/满级/穿戴卸下/移除
- **不可能模式调试**：词缀概率自定义、所有难度出词缀开关
- **隐藏功能**：死神之指开关

## 开发说明（双仓库铁律）

- 本仓库与正式版（`web/rougelike`）共享全部游戏逻辑文件；**改动共享文件（js/css/index.html）必须同步两仓库**：改正式版 → 全量复制到本仓库（保留 debug.html / debug.js / debug.css 三件套不动）→ 校验 MD5 一致 + 双方 `node --check` 通过
- **index.html 新增 DOM 元素时，debug.html 必须同步补齐**（共享 js 会在加载时绑定元素，缺失会导致启动崩溃）
- JS 文件为顶层共享作用域，按固定顺序加载，新增 JS 文件请保持依赖顺序
- 快捷键：`P` / `Esc` 暂停，`M` 静音，空格暂停/继续，`F1` Debug 面板（仅 debug.html）
